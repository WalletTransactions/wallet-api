# currency-route-rates Specification

## Purpose
Составной курс валюты по маршруту из нескольких шагов: как маршрут леджера
превращается в курс для серверных расчётов эквивалента (остатки, серии,
капитал, отчёты), когда прямой пары нет.

## Requirements

### Requirement: Цепочка шагов маршрута
Маршрут `from → to` леджера SHALL состоять из шагов с номерами `1…N` (N не
больше 3); каждый шаг называет валютную пару и направление. Цепочка валидна,
если номера идут подряд с 1, шаг 1 начинается в `from`, каждый следующий шаг
начинается там, где закончился предыдущий, а последний заканчивается в `to`.
Невалидная цепочка SHALL не давать курса.

#### Scenario: Недостроенная цепочка
- **WHEN** у маршрута `BTC → RUB` есть шаг 1, но нет шага 2
- **THEN** курса BTC→RUB по маршруту нет

#### Scenario: Шаги не стыкуются
- **WHEN** шаг 1 заканчивается в `EUR`, а шаг 2 начинается в `USD`
- **THEN** курса по маршруту нет

### Requirement: Составной курс маршрута
Курс `from→to` на дату SHALL равняться произведению курсов шагов на эту дату.
Курс шага — по правилам курса на дату: последний живой курс пары не позже даты;
для шага в обратном направлении — `1 / курс`. Курсы видимых леджеру пар
(общих и собственных) учитываются так же, как для обычного пересчёта.

#### Scenario: Два шага
- **WHEN** маршрут `BTC → EUR → RUB`, курс BTC→EUR на дату — 90 000, EUR→RUB — 100
- **THEN** курс BTC→RUB на эту дату — 9 000 000

#### Scenario: Шаг по обратной паре
- **WHEN** шаг `EUR→RUB` обеспечен парой `RUBEUR` с курсом 0,01 (шаг записан как обратный)
- **THEN** курс шага — 100

#### Scenario: Три шага
- **WHEN** маршрут `BTC → USD → EUR → RUB` с курсами шагов 60 000, 0,9 и 100
- **THEN** курс BTC→RUB — 5 400 000

### Requirement: Независимые даты шагов
Каждый шаг SHALL браться «последний курс не позже даты» независимо от
других; составной курс на дату существует, только если у всех шагов есть
курс не позже этой даты. Курс меняется на дату изменения любого из шагов.

#### Scenario: Шаги заведены в разные дни
- **WHEN** BTC→EUR последний раз заведён 01.11, EUR→RUB — 10.11, нужен курс на 12.11
- **THEN** используются курс 01.11 и курс 10.11

#### Scenario: Один из шагов позже даты
- **WHEN** первый курс EUR→RUB заведён 10.11, нужен курс BTC→RUB на 05.11
- **THEN** курса BTC→RUB нет

### Requirement: Маршрут действует в обе стороны
Маршрут `A → … → C` SHALL давать и курс `C→A`, равный `1 / курс A→C` на ту же
дату.

#### Scenario: Обратное направление
- **WHEN** есть маршрут `BTC → EUR → RUB`, нужен курс RUB→BTC
- **THEN** курс определён и равен `1 / курс BTC→RUB` на эту дату

### Requirement: Прямая пара приоритетнее маршрута
Если у пары валют `from`/`to` есть хотя бы один живой прямой курс (по прямой или
обратной паре, видимой леджеру), маршрут между ними SHALL не применяться на
любую дату. Маршрут работает только там, где прямого курса нет вовсе.

#### Scenario: Прямая пара есть
- **WHEN** у леджера есть пара `BTCRUB` с курсом на 01.11 и маршрут `BTC → EUR → RUB`
- **THEN** курс BTC→RUB на любую дату берётся из пары `BTCRUB`, а не из маршрута

#### Scenario: Прямая пара удалена
- **WHEN** единственная пара `BTCRUB` мягко удалена
- **THEN** курс BTC→RUB снова считается по маршруту

### Requirement: Кросс-курс через USD по умолчанию
Для пары валют `A`/`B` (обе не USD), у которой нет ни живого прямого курса, ни
структурно валидного явного маршрута, курс SHALL считаться через USD как
маршрут `A → USD → B` из двух шагов: курс `A→USD` и курс `USD→B`, каждый — по
живому прямому курсу (по прямой или обратной паре). USD — валюта с
`iso_code` = `USD`, видимая леджеру (своя перекрывает общую). Цепочки через
USD из нескольких кросс-шагов SHALL не строиться. Нет USD, или нет прямого
курса у любого из двух шагов — курса нет.

#### Scenario: Кросс через USD
- **WHEN** есть пары `BTCUSD` (курс 60 000) и `USDRUB` (курс 90), явного маршрута и пары `BTCRUB` нет
- **THEN** курс BTC→RUB — 5 400 000, обратный RUB→BTC — `1 / 5 400 000`

#### Scenario: Шаг по обратной паре
- **WHEN** есть `EURUSD` (1,1) и `RUBUSD` (0,011), пары `EURRUB` и явного маршрута нет
- **THEN** курс EUR→RUB равен `1,1 / 0,011` = 100

#### Scenario: Нет второго шага
- **WHEN** есть `BTCUSD`, а пары между USD и RUB нет
- **THEN** курса BTC→RUB нет

#### Scenario: Сама валюта USD
- **WHEN** нужен курс BTC→USD, прямой пары нет
- **THEN** кросс-курс через USD не строится, курса нет

### Requirement: Приоритет источников курса
Курс пары валют SHALL браться из первого доступного источника: живой прямой
курс; иначе явный маршрут леджера; иначе кросс через USD. Структурно валидный
явный маршрут без курса у шага SHALL блокировать кросс через USD для этой
пары: курса нет, молчаливой подмены нет.

#### Scenario: Явный маршрут против USD
- **WHEN** есть маршрут `BTC → EUR → RUB` и пары `BTCUSD`, `USDRUB` с курсами
- **THEN** курс BTC→RUB считается по маршруту через EUR

#### Scenario: Маршрут без курса
- **WHEN** маршрут `BTC → EUR → RUB` валиден, но у шага `EUR→RUB` нет курса, а `BTCUSD` и `USDRUB` есть
- **THEN** курса BTC→RUB нет

#### Scenario: Прямая пара приоритетнее всего
- **WHEN** есть пара `BTCRUB` с курсом, маршрут и кросс через USD тоже возможны
- **THEN** курс берётся из пары `BTCRUB`

### Requirement: Обрыв маршрута
Если у любого шага нет живого курса (пара не заведена или удалена, курсы
удалены, валюта удалена), составного курса SHALL не быть: пересчёта 1:1 нет,
эквивалент не считается — как при полном отсутствии курса.

#### Scenario: Пара шага удалена
- **WHEN** пара шага `EURRUB` мягко удалена на телефоне, а шаги маршрута остались
- **THEN** курса BTC→RUB по маршруту нет

#### Scenario: Удалённая промежуточная валюта
- **WHEN** промежуточная валюта `EUR` мягко удалена
- **THEN** составных курсов по маршруту нет

### Requirement: Маршруты изолированы по леджеру
Составной курс SHALL строиться по маршрутам только того леджера, для которого
считается расчёт.

#### Scenario: Маршрут соседа
- **WHEN** маршрут `BTC → EUR → RUB` есть только у леджера L1
- **THEN** у леджера L2 курса BTC→RUB по нему нет

### Requirement: Тождественный курс не затрагивается
Курс валюты в саму себя SHALL оставаться 1 с 2000-01-01; маршрут не создаёт и
не меняет его.

#### Scenario: Эквивалент в валюте кошелька
- **WHEN** валюта эквивалента совпадает с валютой кошелька
- **THEN** курс 1, маршруты не участвуют
