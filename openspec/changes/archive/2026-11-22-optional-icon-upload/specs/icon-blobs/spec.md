# Spec Delta

## ADDED Requirements

### Requirement: Загрузка содержимого и флаг приёма иконок
При выключенном флаге загрузки своих иконок (`icon-upload-flag`) `POST
/sync/blobs` SHALL отвечать `403` с `{"error":"icon_upload_disabled"}` для
вызывающего без роли администратора, не читая и не сохраняя тело. Проверка
флага SHALL идти после аутентификации и до проверки размера тела. Вызывающему
с ролью администратора загрузка SHALL проходить независимо от флага. При
включённом флаге поведение не меняется.

#### Scenario: Пользователь при выключенном флаге
- **WHEN** флаг выключен и пользователь без роли администратора загружает 4 КиБ
- **THEN** ответ `403` с `error` = `icon_upload_disabled`, в хранилище ничего не добавлено

#### Scenario: Администратор при выключенном флаге
- **WHEN** флаг выключен и администратор загружает 4 КиБ
- **THEN** ответ `200` с SHA-256 содержимого

#### Scenario: Неаутентифицированный запрос
- **WHEN** флаг выключен и запрос пришёл без токена
- **THEN** ответ `401`, а не `403`
