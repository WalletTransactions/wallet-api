# Proposal

## Why

Общие иконки (`icon`, `ledger_id IS NULL`) сейчас появляются в базе только
вручную: администратор загружает их с экрана «Иконки» на вебе. На чистой
базе — после `test-refresh` 2026-11-13 в `icon` и `blob` по 0 строк — это
ломает два клиента сразу. Веб остаётся без флагов в форме валют, а телефон по
`icon-sync` не находит серверную иконку-заместителя для своих встроенных
иконок и откладывает каждую строку, которая на них ссылается: `POST
/sync/push` не уходит вовсе (android-wallet#44). Стартовый набор телефона уже
переведён на Fluent 3D (android-wallet#29, коммит `5afc633`); сервер должен
иметь тот же набор по умолчанию, а не ждать разовой загрузки.

## What Changes

- Новая миграция `000037_default_reference_icons` кладёт в `blob` и `icon`
  общий набор иконок — ту же картинку и то же имя, что у `seed.json`
  телефона: категории Fluent 3D, флаги и запасная иконка `unknown`.
- Миграция идемпотентна и не затирает работу администратора: иконка с именем,
  под которым уже есть живая общая иконка, пропускается; повторный накат
  дублей не создаёт.
- Откат (`down`) убирает только иконки этого набора (по детерминированным
  `uuid`) и осиротевшие `blob`, иконки администратора не трогает.
- Генератор `scripts/gen_default_icons.py` собирает SQL миграции и PNG-файлы
  набора из `seed.json` и `res/drawable` телефона; 11 флагов, которые на
  телефоне векторы Android XML, растеризуются в PNG. PNG набора лежат в
  репозитории, миграция воспроизводима без доступа к `android-wallet`.
- API, контракты `/sync/*` и клиенты не меняются. **BREAKING** нет:
  существующие иконки не меняются, набор только добавляется.

## Capabilities

### New Capabilities
- `default-reference-icons`: общий набор иконок, который есть в базе после
  миграций, — состав, соответствие имён телефонному набору, идемпотентность,
  уважение иконок администратора и откат.

## Impact

- `wallet-api/migrations/000037_default_reference_icons.up.sql` и `.down.sql`
  (около 3 МБ SQL: картинки в hex), `migrations/default_icons/*.png`,
  `scripts/gen_default_icons.py` и его тест.
- `tests_integration` — проверка миграции на пустой базе, на повторном накате,
  на базе с иконкой администратора, на откате и выдачу набора через
  `GET /sync/pull` потока `reference`.
- `VERSION` (патч 0.4.1) и README миграций; rc-тег выката на test — отдельной
  задачей после слияния.
- Другие сервисы: `android-wallet` не меняется (проверяется, что заместитель
  по имени находит набор), `wallet-web` и `wallet-report` просто видят иконки.
  После выката на test снимается блок проверки `archive-wallet-writeoff`
  (android-wallet#44).
