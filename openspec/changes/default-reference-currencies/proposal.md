# Proposal

## Why

Общий справочник валют и валютных пар (`currency` / `currency_pair` с `ledger_id IS NULL`) на сервере пуст: общие валюты заводит только администратор вручную, а на test их 0 из 46 (все валюты и пары — «свои» в леджере). Из-за этого:

- валюты стартового набора телефона (`new-user-default-set`) уходят в кошелёк нового человека как **свои**, а не как общие — у телефона нет серверного ключа, с которым принять строку при входе (`принятие по ключу`);
- ветку «Общая валюта на английском телефоне» (`currency-directory`: название общей валюты по ISO на языке телефона) нельзя проверить вживую — общих валют нет (задача 1.5 `new-user-default-set`);
- чистая база (после `test-refresh` или на новом томе) без ручной загрузки остаётся без справочника, тогда как иконки уже приходят миграциями (`000037`, `000038`).

## What Changes

- Новая миграция `000039_default_reference_currencies` кладёт в `currency` и `currency_pair` общий справочник — те же 17 валют и 31 пара без курсов, что в `seed.json` телефона: код, название, символ, иконка (по имени из набора иконок), точность (BTC и LTC — 8).
- Миграция идемпотентна и не затирает работу администратора: валюта с кодом или названием (без учёта регистра), уже занятыми живой общей валютой, и пара с занятым символом пропускаются; удалённые строки не воскресают.
- Откат (`down`) убирает только валюты и пары набора (по детерминированным `uuid`); строка, на которую кто-то ссылается (внешний ключ), остаётся.
- Генератор `scripts/gen_default_currencies.py` собирает манифест из `seed.json` телефона и пишет SQL; манифест лежит в репозитории, миграция воспроизводима без `android-wallet`.
- API и контракты `/sync/*` не меняются; клиенты получают справочник обычным проходом синка (`reference`-поток). **BREAKING** нет: существующие валюты и пары не меняются.

## Capabilities

### New Capabilities
- `default-reference-currencies`: общий справочник валют и пар по умолчанию — состав, соответствие стартовому набору телефона, идемпотентность, уважение работы администратора, откат.

### Modified Capabilities
<!-- нет -->

## Impact

- Код: `scripts/gen_default_currencies.py`, `scripts/tests/test_gen_default_currencies.py`, `migrations/000039_*.sql`, `migrations/default_currencies/manifest.json`, `tests_integration/test_default_currencies.cpp`.
- Документация: `README.md` («Справочник валют по умолчанию»), `scripts/README.md`.
- Клиенты: телефон принимает общую валюту вместо своей по ключу при подключении (spec `ledger-connection`); у леджеров, где уже есть своя валюта с тем же кодом, рядом появляется общая — клиент при совпадении кода предпочитает свою строку.
- Вне объёма: курсы валют (справочник без курсов), наполнение справочника сверх набора телефона.
