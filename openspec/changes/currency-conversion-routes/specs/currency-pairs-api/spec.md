# Spec Delta

## MODIFIED Requirements

### Requirement: Правка и удаление своей пары
`PATCH /api/currency-pairs/{uuid}` с целой `precision` 0–10 SHALL менять
точность своей пары и возвращать её. `DELETE` мягко удаляет свою пару, все её
живые курсы и все живые маршруты пересчёта, шаги которых используют эту пару
(целиком, все шаги маршрута), одной группой (`204`). Общая или чужая пара —
`404`.

#### Scenario: Попытка удалить общую пару
- **WHEN** пользователь удаляет пару с `is_own` = `false`
- **THEN** ответ `404`, пара не изменена

#### Scenario: Пара используется маршрутом
- **WHEN** пользователь удаляет свою пару `EURRUB`, являющуюся шагом маршрута `BTC → EUR → RUB`
- **THEN** пара, её курсы и все шаги этого маршрута помечены удалёнными одним `seq`; в списке маршрутов его нет

#### Scenario: Пара не в маршрутах
- **WHEN** пользователь удаляет пару, которую не использует ни один маршрут
- **THEN** маршруты не изменены
